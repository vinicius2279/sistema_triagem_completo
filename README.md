# Sistema Completo de Triagem utilizando Java e MySQL

## Tecnologias utilizadas

- Java
- JavaFX
- MySQL
- Maven
- Wix Toolset

## Como executar o projeto

  1. Baixe o arquivo .exe ou execute o código desse repositório numa IDE compatível com Java 26
  2. Instale e inicie o MySQL Server
  3. No Workbench, crie ou conecte-se a uma instância local do MySQL.
  4. Execute os arquivos da pasta `database` nesta ordem:
 -  `triagemdb_schema.sql`
 - `triagemdb_seed_basico.sql`
  5. Verifique se o banco local se chama `triagemdb`
  6. Verifique as credenciais e altere o que for necessário.
  7. Execute o arquivo .exe ou a classe principal do projeto.
  8. Teste o sistema com os usuários de demonstração, verificando qual é o admnistrador caso queira adicionar, editar ou excluir funcionários.
